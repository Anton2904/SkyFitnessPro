# SkyFitnessPro

Дипломный проект на React + TypeScript + Vite.

## Запуск

1. Скопируйте `.env.example` в `.env`.
2. Укажите API:
   `VITE_API_URL=https://webdev-hw-api-iota.vercel.app/api/fitness`
3. Выполните:

```bash
npm install
npm run dev
```

## Проверки

```bash
npm run lint
npm run build
```

## Реализовано

- список курсов из API;
- адаптивные карточки и страница курса;
- регистрация, вход и выход;
- добавление и удаление курсов;
- защищённый профиль;
- выбор тренировок;
- видео, упражнения и сохранение прогресса;
- сброс прогресса курса;
- обработка ошибок API и валидация форм.

## Исправления по итогам проверки диплома

- прогресс тренировки обновляется сразу после сохранения без перезагрузки страницы;
- галочка отображается только у полностью выполненной тренировки;
- прогресс курса отображается в виде прогресс-бара;
- общий прогресс рассчитывается по упражнениям всех тренировок курса;
- иконка в правом верхнем углу карточки добавляет или удаляет курс без перехода на страницу курса;
- добавлены тесты на Vitest и React Testing Library.

### Запуск тестов
